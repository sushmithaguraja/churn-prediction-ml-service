# Customer Churn Prediction – ML Service

This project builds a machine learning system to predict whether a customer is likely to churn based on historical data.

## Project Goals
- Train a churn prediction model
- Evaluate model performance
- Serve predictions using an API

## Tech Stack
- Python
- pandas, scikit-learn
- FastAPI

## Project Structure
data/        -> dataset  
notebooks/  -> data exploration  
src/        -> training and evaluation code  
app/        -> API code
